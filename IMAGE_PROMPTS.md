# ArtBridge — Gallery artwork

Generated with the built-in image_gen tool for the November 2026 visual redesign. These are original fictional concept covers, not completed user projects. Originals remain in the generator output directory; the website uses its own local copies in `assets/artworks/`.

Visual direction: a dark art-browsing workspace with image-led masonry, restrained navigation and typography. Midjourney's Explore experience was a UI reference; no Midjourney logo, artwork or code was copied.
