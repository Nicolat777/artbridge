# ArtBridge 网页原型

一个可以直接部署到 GitHub Pages 的静态网站。当前采用深色侧边导航、艺术封面和瀑布流作品展板。使用 HTML、CSS 和原生 JavaScript，无需安装前端依赖，也无需构建。

## 已有功能

- 中文、英文切换，电脑与手机布局。
- 六个明确标注的概念项目，首页与项目广场均支持关键词、所需技能、协作语言和收藏筛选。
- 项目详情、合作指南、等待真实作品的成果展示页。
- 发起项目与合作申请的填写界面。
- 在当前浏览器保存草稿与收藏，导出或复制草稿文本。
- 浏览器存储不可用时给出提示；可清除本机数据。

当前不含账号、共享数据库、即时聊天或文件上传。示例项目没有真实接收方。保存、复制和导出都不会向任何人发送信息。

## 先在电脑上查看

在本文件所在文件夹打开终端，运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4173/`。结束时在终端按 Ctrl+C。

也可以直接打开 `index.html` 查看页面，但不同浏览器对本地文件的存储行为可能不同，草稿和收藏建议通过上述本机服务器测试。

## 上传到 GitHub Pages

1. 创建 ArtBridge 专用仓库。使用 GitHub Free 时，选择公开仓库以使用 Pages。
2. 解压上传包，将**里面的文件和文件夹**上传到仓库根目录。根目录应直接看到 `index.html`、`css`、`js`、`assets`，不要只上传 ZIP，也不要多套一层 `artbridge` 文件夹。
3. 提交文件后，在仓库的 **Settings → Pages** 中设置：
   - Source：**Deploy from a branch**
   - Branch：**main**（或你的实际分支）
   - Folder：**/(root)**
4. 点击 Save，等发布完成后，使用 Pages 页面显示的实际网址。

项目站点通常采用 `https://用户名.github.io/仓库名/`。本网站全部使用相对路径，可以放在仓库子路径下。

官方部署说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

GitHub Pages 对经营线上业务、商业交易及商业 SaaS 有用途限制。本版本用于项目展示与原型验证；正式商业运营前应选择允许该用途的托管方案。

官方限制：https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

## “表单链接”是什么

这是一个在线登记页，访客在那里正式提交项目或报名信息，你可以在表单服务的后台看到答复。目前没有配置这类服务，所以网站诚实地显示“提交入口待开放”，而不会假装已收到报名。

在 `js/config.js` 中可以填写公开的 HTTPS 表单地址：

```js
window.ARTBRIDGE_CONFIG = {
  publishFormUrl: '', // 项目登记表的公开填写地址
  joinFormUrl: '',    // 合作申请表的公开填写地址
  defaultLanguage: 'zh'
};
```

项目登记表建议包含：昵称、项目名称、目标、需要的技能、协作语言、周期、作品链接、联系方式与联系同意说明。

当前采用最简单的衔接方式：用户填写本机草稿，复制内容，点击入口前往外部表单，再在那里粘贴并提交。网站不会自动将草稿发送到外部服务。示例项目始终只用于申请流程练习。

接入真实项目、启用真实申请入口前，需要同时核对项目标记、接收表单、审核流程、招募状态和页面上的原型说明；仅填写 `joinFormUrl` 不会让示例项目变成真实招募。

不要在配置文件或公开仓库中放密码、访问令牌、报名答复、私密联系方式。公开配置只应包含允许所有访客看到的信息。

## 文件位置

| 文件 | 用途 |
| --- | --- |
| `index.html` | 首页 |
| `explore.html` | 项目广场 |
| `project.html?id=blue-hour` | 项目详情示例 |
| `submit.html` | 发起项目草稿 |
| `join.html?id=blue-hour` | 合作申请草稿示例 |
| `showcase.html` | 成果展示 |
| `guide.html` | 合作指南与常见问题 |
| `js/data.js` | 六个示例项目的中英文内容 |
| `js/config.js` | 公开表单链接与默认语言 |
| `js/app.js` | 页面内容、翻译和交互 |
| `css/style.css` | 视觉样式与响应式布局 |
| `assets/artworks/` | 六张随网站打包的原创艺术概念封面（PNG） |
| `assets/favicon.svg` | 网站图标 |
| `IMAGE_PROMPTS.md` | 封面生成方式、提示词和素材路径 |

## 试用前检查

请分别找一位国内和海外用户测试：打开首页、切换语言、打开项目详情、保存并重新打开草稿。如果配置了外部表单，也要验证表单能打开、提交后运营者能看到答复。自动浏览器测试无法代替两地实际网络验证。

本机数据只存在当前浏览器，不是备份。使用共用设备后，在页脚“数据与隐私”中清除数据；重要草稿请自行导出保存。

## 视觉版本说明

当前是画廊版视觉：深灰画布、固定侧边导航、错落的图像排列，以及简洁的项目说明。艺术封面使用内置 image_gen 工具制作，均为虚构项目的概念素材，不代表真实用户已完成的作品。完整提示词见 `IMAGE_PROMPTS.md`。图像、脚本和样式都随网站打包，不依赖外部字体或图片 CDN。
